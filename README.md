# KartenPokédex v3.9

Neu in v3.9:

- Beim Tippen auf „Karte hinzufügen“ wählst du jetzt zuerst zwischen Einzelkarte und Stapelmodus.
- Das Formular zum Hinzufügen wurde deutlich kompakter aufgebaut.
- Im Stapelmodus verschwinden die alten Galerie-/Stapel-Buttons vollständig und verschwenden keinen Platz mehr.
- Menge und „Tauschbar ab“ stehen nebeneinander, damit weniger gescrollt werden muss.
- Die Speicher-Aktionen sitzen unten als kompakter Footer, im Stapelmodus mit „Bild überspringen“ direkt daneben.
- Die restlichen Funktionen aus v3.8 bleiben erhalten, einschließlich Duplikatwarnung, Pokédex-Vergleich und automatischem Zuschnitt.
